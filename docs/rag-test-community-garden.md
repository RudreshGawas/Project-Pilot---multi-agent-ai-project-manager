# Community Garden Planner - Test Brief

## Project scope

Build a web app for one community garden with 20 plots. Gardeners can request
plots, and a coordinator must approve each request before a plot is assigned.

## Planning details

- Track each plot as available, requested, or assigned.
- Record the crop, planting date, and expected harvest date for each assignment.
- Gardeners must not be able to see other gardeners' email addresses.
- Coordinators can view contact details to manage plot requests.
- Version 1 does not include payments, social features, or external integrations.

## Ground-truth questions

- How many plots does the first version manage? 20.
- Who approves plot requests? A garden coordinator.
- Which planting details are tracked? Crop, planting date, and expected harvest date.
- Are payments or external integrations in scope? No.
